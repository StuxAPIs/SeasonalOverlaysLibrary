Privacy Policy

Effective: September 2026

The short version

This is a plain static HTML site — documentation and a live demo for the SeasonalOverlaysLibrary JavaScript library — hosted on GitHub Pages. There's no server-side code, no database, no account system, and no forms of any kind — so there's nothing for us to collect.

This website

There is no email signup, newsletter, contact form, or any other way to submit information on this page beyond the "Contact Us for Support" button, which just opens your own email client — nothing is sent to us through the page itself.

The Fredoka font is served from this same domain, not a third-party CDN. The only resource loaded from outside this domain is the logo and icon images, from global.media.stuxapis.net — infrastructure operated by the same Stux Group Ltd chain that runs this page, not an unrelated third party.

localStorage

The only thing this page stores in your browser is a single value, stuxapis-theme, remembering whether you last chose light or dark mode. It never leaves your device, isn't sent to any server, and can be cleared any time via your browser's site data settings.

Children's privacy

This page isn't directed at children, but since it collects no personal information from anyone, there's nothing specific to say beyond that.

Changes to this policy

If this page grows features that collect data, this policy will be updated first to reflect exactly what's collected and why. The date above marks the most recent revision.
