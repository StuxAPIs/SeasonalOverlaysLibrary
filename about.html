About

A dependency-free JavaScript library for brief, full-viewport particle overlays.

SeasonalOverlaysLibrary recreates the click-triggered particle animation from Butlin's homepage (pumpkins for Halloween, snow for Christmas) as a small, reusable, MIT-licensed library — no dependencies, no build step, just a single <script> tag.

What it does

  • A growing set of built-in presets (snow, fireworks, leaves, confetti, hearts, rainbows, sunny, pumpkins, skulls & ghosts, nyancat, and more) — see the full list, including composable ones like leaves/halloween/christmas/sunny and a random preset
  • Triggers via a data-overlay-preset attribute (no JS required) or the SeasonalOverlaysLibrary.start() API
  • An optional seasonal calendar that resolves today's date to a preset automatically

Who's behind this

Built & Maintained by StuxAPIs, Hosted by Stuxedo. The source is fully open on GitHub.
